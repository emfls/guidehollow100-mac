맥북에서 '시동 디스크가 거의 찼습니다'라는 알림이 뜨거나 macOS 업데이트를 설치할 공간이 부족할 때, 가장 먼저 해야 할 일은 캐시를 무작정 삭제하는 것이 아닙니다. **어떤 데이터가 실제 공간을 차지하는지 확인하고, 복구할 수 있는 상태에서 불필요한 파일부터 정리해야 합니다.** 특히 저장 공간 막대에 '시스템 데이터'가 크게 표시된다는 이유로 시스템 폴더를 직접 지우면 앱 오류나 데이터 손실이 생길 수 있습니다.

이 글은 **macOS Ventura 13 및 이후 버전**의 '시스템 설정 > 일반 > 저장 공간'을 기준으로 설명합니다. macOS 버전과 설치된 앱에 따라 메뉴나 표시 카테고리가 다를 수 있습니다. Apple Silicon과 Intel Mac 모두에 적용할 수 있는 일반적인 확인 방법이며, 실제 기기에서 용량 절감량을 측정한 글은 아닙니다.

## 핵심 요약: 이 순서대로 확인하세요

1. 저장 공간 화면에서 현재 사용 가능한 용량과 큰 항목을 기록합니다.
2. 중요한 사진·문서·프로젝트의 백업을 먼저 확인합니다.
3. 다운로드, 큰 문서, 사용하지 않는 앱을 차례로 점검합니다.
4. 오래된 기기 백업, 첨부 파일, 오프라인 미디어를 확인합니다.
5. 휴지통의 파일을 다시 검토한 후 필요할 때 비웁니다.
6. 마지막에 '시스템 데이터'와 Time Machine 스냅샷의 특성을 확인합니다.

**목표는 시스템 데이터 숫자를 0으로 만드는 것이 아니라, 중요한 파일을 보존하면서 실제로 사용할 수 있는 저장 공간을 늘리는 것입니다.**

## 1. 맥북 저장 공간에서 무엇이 큰지 확인하기

화면 왼쪽 위 Apple 메뉴()에서 **시스템 설정 > 일반 > 저장 공간**을 엽니다. 저장 공간 막대에는 사용한 공간과 사용 가능한 공간이 표시됩니다. '문서', '응용 프로그램', '사진', 'iOS 파일', 'Mail', '메시지', '시스템 데이터' 등 카테고리를 살펴보세요.

먼저 사용 가능한 공간을 메모해 두고, 크기가 큰 항목을 두세 개 확인합니다. 정리한 후 같은 화면에서 변화를 비교하면 무엇이 효과가 있었는지 파악하기 쉽습니다. 카테고리는 앱과 파일에 따라 달라지고, 분류 작업이 진행되는 동안 숫자가 바뀔 수 있으므로 표시값을 절대적인 실시간 측정으로 여기지 마세요.

저장 공간 화면에 **모든 볼륨**이 보이면 열어 보세요. 내장 디스크에 여러 볼륨이나 컨테이너가 있는 경우 볼륨별 정보가 표시될 수 있습니다. 외장 디스크나 다른 볼륨과 혼동하여 엉뚱한 파일을 정리하지 않도록 실제로 공간이 부족한 디스크를 먼저 확인하는 것이 중요합니다.

### '시스템 데이터'는 무엇인가요?

Apple 공식 설명에 따르면 시스템 데이터에는 로그, 캐시, 가상 메모리 관련 파일, 임시 파일, 앱 지원 파일, 플러그인과 다른 분류에 속하지 않는 데이터 등이 포함됩니다. 하나의 독립된 폴더가 아니며 macOS가 관리하는 항목도 있으므로 저장 공간 화면에서 직접 해당 카테고리를 선택해 일괄 삭제할 수 없습니다.

따라서 '시스템 데이터 50GB'처럼 특정 숫자를 보았다고 해서 그 용량 전체가 불필요한 파일이라고 판단할 수는 없습니다. 숫자가 크다면 먼저 사용자 파일을 정리하고, 작업 후 사용 가능 공간을 다시 확인하세요.

## 2. 파일을 삭제하기 전에 백업부터 점검하기

공간이 급해도 중요한 자료는 먼저 보호해야 합니다. Time Machine을 사용한다면 **마지막으로 백업이 성공한 시각과 백업 디스크 상태**를 확인하세요. 외장 저장 장치로 새 백업 디스크를 설정하는 과정에서는 선택한 디스크의 기존 데이터가 지워질 수 있으므로 안내 문구를 주의 깊게 읽어야 합니다.

Time Machine이 설정되지 않았다면 중요한 업무 문서, 사진, 영상 프로젝트, 계정 복구용 파일 등을 이미 보유한 별도 저장 위치에 복사하고 실제로 열리는지 확인할 수 있습니다. 다만 동일한 내부 디스크의 다른 폴더로 옮긴 것은 디스크 고장에 대비한 백업이 아닙니다.

iCloud 동기화가 켜져 있다는 사실도 삭제 전의 독립적인 백업을 보장하지는 않습니다. 동기화 중인 파일을 삭제하면 다른 기기에서도 삭제가 반영될 수 있기 때문입니다. 특히 바탕화면·문서 폴더를 iCloud Drive와 동기화하고 있다면 먼저 파일 원본이 어디에 보관되어 있는지 확인하세요.

## 3. 다운로드와 큰 문서부터 안전하게 정리하기

대부분의 사용자에게 가장 쉬운 출발점은 Finder의 **다운로드** 폴더와 저장 공간의 **문서** 카테고리입니다.

1. Finder에서 다운로드 폴더를 엽니다.
2. 목록 보기로 바꾸고 크기가 큰 항목을 찾습니다.
3. 압축 파일, 설치용 디스크 이미지, 영상 파일, 중복 문서를 하나씩 엽니다.
4. 원본이 보존되어 있고 더 이상 필요하지 않다는 것을 확인한 파일만 휴지통으로 옮깁니다.
5. 시스템 설정의 저장 공간으로 돌아가 '문서' 카테고리에서도 큰 파일을 확인합니다.

오래된 설치 파일은 앱 설치가 끝난 뒤에도 남아 있을 수 있지만, 나중에 오프라인 재설치할 때 필요한 경우도 있습니다. 파일 확장자만 보고 삭제하지 마세요. 이름이 비슷한 문서 두 개가 서로 다른 수정본일 가능성도 있습니다.

사진과 영상은 특히 주의해야 합니다. 사진 앱의 보관함 내부 파일을 Finder에서 직접 찾아 삭제하는 것은 권장하지 않습니다. 사진 보관함은 연결된 데이터 구조를 사용하기 때문에 일부 파일을 임의로 제거하면 정상적인 관리에 문제가 생길 수 있습니다.

## 4. 사용하지 않는 앱과 추가 콘텐츠 확인하기

저장 공간의 **응용 프로그램** 카테고리를 열고 큰 앱부터 사용 여부를 점검합니다. 사용하지 않는 앱은 공간 확보 후보가 되지만, 앱을 지울 때 연결된 사용자 데이터까지 사라지는지 확인해야 합니다.

일부 앱은 Finder의 응용 프로그램 폴더에서 제거할 수 있고, 전문 소프트웨어나 보안 프로그램은 개발사에서 제공하는 제거 도구가 필요할 수 있습니다. 항상 해당 앱의 공식 제거 지침을 우선하세요. 앱을 삭제한다고 앱의 모든 라이브러리와 프로젝트가 안전하게 보존된다고 보장할 수는 없습니다.

음악·영상 제작 앱에는 별도 음원, 샘플, 오프라인 콘텐츠가 있을 수 있습니다. 필요 없는 항목을 제거할 때는 가능하면 **해당 앱의 콘텐츠 관리 기능**을 사용하세요. 앱 지원 폴더 전체를 Finder에서 직접 삭제하는 방식은 피해야 합니다.

## 5. iPhone 백업과 메일·메시지 첨부 파일 확인하기

### iOS 파일

Mac에 iPhone 또는 iPad를 백업한 적이 있다면 'iOS 파일' 카테고리에 기기 백업 및 관련 데이터가 있을 수 있습니다. 어느 기기와 시점의 자료인지 확인한 뒤, 복원에 필요하지 않은 오래된 백업만 정리하세요.

기기를 교체했더라도 이전 백업에만 남아 있는 자료가 있을 수 있습니다. 현재 기기의 최신 백업이 존재한다는 사실이 이전 백업의 불필요함을 증명하지는 않습니다. 삭제 전 기기 이름, 날짜, 복원 필요성을 확인해야 합니다.

### Mail과 메시지

메일 및 메시지에서 주고받은 대용량 사진, 동영상, PDF는 공간을 차지할 수 있습니다. 다만 첨부 파일이나 대화를 삭제하면 사용하는 계정과 동기화 설정에 따라 다른 기기에도 영향을 줄 수 있습니다. 각 앱에서 해당 자료를 확인한 후 필요하지 않은 경우에만 정리하세요.

### 내려받은 미디어

오프라인 재생을 위해 저장한 영상·음악·기타 콘텐츠도 점검할 수 있습니다. 앱에서 다시 내려받을 수 있는지, 오프라인 상태에서 계속 필요한지 확인한 후 공식 관리 메뉴를 이용하세요. 보관함 내부 파일을 Finder로 직접 지우는 일은 피합니다.

## 6. 휴지통은 마지막에 비우기

휴지통에 옮긴 파일이 저장 공간을 계속 차지할 수 있습니다. 하지만 휴지통을 비우고 나면 파일을 되돌리는 일이 어려워집니다. 따라서 휴지통을 열어 삭제하려던 항목을 다시 확인한 뒤 비우세요.

- 작업 중이던 문서나 프로젝트 파일이 있는지 확인합니다.
- 비슷한 이름의 원본과 수정본을 혼동하지 않았는지 확인합니다.
- 가족이나 동료와 공유하는 Mac이라면 다른 사람의 자료가 아닌지 살핍니다.
- 중요한 파일의 별도 사본이 실제로 열리는지 확인합니다.

macOS에는 오래된 휴지통 항목을 자동으로 지우는 설정도 있습니다. Apple 안내 기준으로 자동 비우기는 휴지통에 30일 이상 있던 항목을 제거합니다. 실수로 파일을 자주 휴지통에 넣는 경우라면 자동 비우기를 켜기 전에 신중히 판단하세요.

## 7. 시스템 데이터가 너무 클 때 해야 할 일

시스템 데이터는 사용자가 보이는 일반 파일과 달리 macOS가 관리하는 로그·캐시·임시 항목을 포함합니다. 일부 캐시와 로그는 공간이 필요할 때 시스템이 자체적으로 정리합니다. 따라서 **시스템 데이터 수치만 줄이려고 삭제 명령을 실행할 필요는 없습니다.**

먼저 큰 사용자 파일, 오래된 앱, 필요 없는 백업을 정리한 뒤 저장 공간을 다시 확인하세요. 필요하다면 작업을 저장하고 Mac을 재시동해 표시 상태를 다시 볼 수 있습니다. 다만 재시동만으로 특정 용량이 항상 확보되는 것은 아닙니다.

다음 행동은 피하세요.

- 의미를 모르는 터미널 삭제 명령어를 그대로 실행하기
- 시스템 폴더 또는 사용자 Library 폴더를 통째로 비우기
- 개발사 설명 없이 앱 지원 파일과 캐시를 일괄 삭제하기
- 정리 프로그램이 제시하는 '즉시 몇 GB 확보' 수치를 무조건 믿기
- 중요한 파일을 백업하지 않은 채 macOS 재설치나 디스크 지우기를 시작하기

일부 캐시는 프로그램을 다시 실행하면 생성됩니다. 캐시를 삭제해도 장기적으로 확보되는 공간이 같다고 보장할 수 없으며, 중요한 앱 설정까지 영향을 받을 수 있습니다.

## 8. Time Machine 로컬 스냅샷은 지워야 하나요?

Time Machine은 백업 디스크가 연결되어 있지 않을 때도 이전 파일 버전을 되찾을 수 있도록 로컬 스냅샷을 만들 수 있습니다. Apple의 공식 설명에 따르면 APFS 디스크에서 사용하며, 일반적으로 시간 단위로 만들어져 오래되거나 디스크 공간이 필요할 때 자동으로 정리됩니다.

가장 중요한 점은 **macOS가 로컬 스냅샷에 사용된 용량을 사용 가능한 공간으로 계산할 수 있다는 것**입니다. 따라서 스냅샷이 존재한다고 해서 그 용량만큼 파일을 새로 저장할 수 없는 것은 아닙니다. 시스템 데이터 숫자가 커 보인다는 이유만으로 스냅샷 삭제를 첫 번째 해결책으로 삼지 마세요.

정말 수동 정리가 필요한 상황에서는 [Apple의 로컬 스냅샷 안내](https://support.apple.com/ko-kr/102154)를 따르세요. 공식 문서는 Time Machine 자동 백업 설정을 일시적으로 조정한 후 다시 켜는 방법을 설명합니다. 이 절차를 사용한다면 **자동 백업을 반드시 다시 활성화**해야 합니다. 백업을 끈 채로 방치하면 나중에 파일을 복원할 기회를 잃을 수 있습니다.

로컬 스냅샷은 같은 내장 디스크에 저장되므로 외부 디스크에 보관하는 정기적인 Time Machine 백업을 대신하지 않습니다.

## 9. iCloud로 공간을 줄일 때 생길 수 있는 문제

저장 공간 설정에는 'iCloud에 저장하기'나 저장 공간 최적화와 관련된 추천이 표시될 수 있습니다. 이 기능은 일부 파일의 원본을 iCloud에 두고 Mac에서 필요한 경우 내려받는 방식으로 공간을 관리할 수 있습니다.

다만 **클라우드에서 파일을 삭제하는 것과 Mac의 로컬 다운로드를 정리하는 것은 다른 행동**입니다. 동기화 폴더에서 파일을 삭제하면 다른 기기에서도 없어질 수 있습니다. 파일 원본이 클라우드에 제대로 저장되었는지 확인하지 않은 채 로컬 파일을 대량으로 지우지 마세요.

출장·이동 중 오프라인으로 열어야 하는 파일이라면 최적화 이후 네트워크가 필요해질 가능성도 고려해야 합니다. 모든 권장 옵션을 한꺼번에 켜기보다 파일 사용 습관에 맞는 기능만 선택하세요.

## 10. 정리했는데도 저장 공간이 늘어나지 않을 때

**휴지통에 파일이 남아 있나요?** 휴지통으로 이동하기만 했다면 실제 공간이 바로 늘어나지 않을 수 있습니다. 삭제 목록을 검토한 뒤 비웠는지 확인하세요.

**다른 볼륨을 보고 있나요?** 저장 공간의 '모든 볼륨' 화면에서 문제가 발생한 내장 디스크의 용량을 확인하세요. 볼륨 또는 외장 디스크의 수치를 혼동할 수 있습니다.

**클라우드·앱이 파일을 다시 내려받나요?** 사진 동기화, 미디어 다운로드, 앱 업데이트 등이 저장 공간을 다시 사용할 수 있습니다. 진행 중인 다운로드나 동기화가 끝난 뒤 비교해 보세요.

**'시스템 데이터' 분류만 비교하고 있나요?** 분류 숫자는 시스템 상태에 따라 변할 수 있습니다. 정리 전후 실제 사용 가능한 공간이 어떻게 바뀌었는지가 더 중요한 판단 기준입니다.

**업데이트 설치가 여전히 실패하나요?** 필요한 파일을 백업하고, macOS 버전과 표시된 오류 문구를 기록해 Apple의 해당 버전 지원 안내를 확인하세요. 저장 공간 부족만이 원인이 아닐 수도 있으므로 시스템 파일 삭제를 반복하지 마세요.

## 11. 삭제 위험과 우선순위 비교

| 확인 대상 | 우선순위 | 삭제 전 확인 |
| --- | --- | --- |
| 다운로드·중복 문서 | 높음 | 원본과 수정본, 재사용 여부 |
| 사용하지 않는 앱 | 높음 | 프로젝트 파일, 재설치 가능 여부 |
| 이전 기기 백업 | 중간 | 해당 기기 복원에 필요한지 |
| Mail·메시지 첨부 | 중간 | 다른 기기 동기화와 보존 필요성 |
| 휴지통 | 최종 확인 | 되돌려야 할 파일이 없는지 |
| 시스템 데이터·스냅샷 | 신중히 검토 | 공식 절차와 백업 상태 |

예를 들어 대용량 영상 파일이 발견됐다면 먼저 파일이 최종 결과물인지 확인하고 별도 사본을 확보한 뒤 삭제 여부를 결정합니다. 그다음 사용하지 않는 앱과 오래된 백업을 점검합니다. 이 순서는 데이터 보존을 우선한 사례이며 특정 크기의 용량 확보를 약속하는 실험 결과가 아닙니다.

## 12. 작업을 마친 뒤 꼭 확인하기

1. 정리 전 기록한 **사용 가능한 공간**과 현재 값을 비교합니다.
2. 중요한 문서, 사진, 영상 프로젝트가 실제로 열리는지 검사합니다.
3. 백업 디스크에 필요한 파일의 사본이 존재하는지 확인합니다.
4. iCloud와 다른 기기에서 의도하지 않은 파일 삭제가 발생하지 않았는지 확인합니다.
5. 저장 공간 부족이 반복되면 어떤 앱이나 다운로드가 공간을 다시 차지하는지 관찰합니다.

시스템 데이터가 조금 남아 있어도 Mac이 정상적으로 작동하고 필요한 저장 공간이 확보됐다면, 숫자 자체를 줄이기 위해 더 위험한 정리를 할 이유는 없습니다.

## 자주 묻는 질문

### 시스템 데이터가 수십 GB면 무조건 문제인가요?

그 크기만으로 정상·비정상을 판단할 수 없습니다. Apple은 다양한 로그, 캐시, VM 파일, 앱 지원 데이터를 이 분류에 포함하며 그 크기가 변할 수 있다고 설명합니다.

### 맥북을 재시동하면 용량이 바로 늘어나나요?

일시적인 작업 상태가 바뀔 수 있지만, 재시동으로 항상 일정한 공간이 확보된다는 보장은 없습니다. 실제 사용 가능 용량을 다시 확인해야 합니다.

### 유료 정리 앱이 필요한가요?

Finder와 macOS 저장 공간 설정만으로도 큰 파일과 앱을 확인할 수 있습니다. 유료 앱은 필수가 아니며 어떤 도구를 쓰더라도 삭제 대상과 백업 여부는 직접 확인해야 합니다.

### Time Machine 스냅샷은 전부 제거해야 하나요?

아니요. Apple은 공간이 필요할 때 스냅샷을 자동으로 정리하며, 그 공간을 사용 가능한 공간으로 계산할 수 있다고 설명합니다. 수동 삭제를 일상적인 첫 단계로 삼지 마세요.
